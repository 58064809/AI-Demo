# 每日 KPI

这个项目用于每天生成运动生活类内容：选题、文案、标签、图片提示词和配图结果。

## 目录

- `AGENTS.md`：给 Codex/AI 代理看的长期工作说明，以后默认按这里执行。
- `prompts/sports_daily_prompts.json`：运动项目、话题池、文案规则和示例。
- `generated_images/YYYY-MM-DD/`：每天的文案和图片输出。

## 每日默认产出

- 3 组运动内容：从羽毛球、飞盘、匹克球、网球中随机选择 3 个，不能重复。
- 每组运动随机匹配 1 个 `topic_pool` 话题。
- 每条包含：标题、4 条图片提示词、分段正文、标签。
- 当天文案保存到 `generated_images/YYYY-MM-DD/文案.md`。
- 每组生成 4 张图，每天共 12 张图，保存到同一个日期目录，建议用 `运动英文名_序号.png` 命名。

## 风格要求

文案要像真实用户分享，生活化、有细节、少广告感。图片优先从网上找清晰、相关、可复用且来源明确的素材；网络图不合适、授权不清、清晰度不够，或需要特定创意画面时，再使用 `gpt-image-2-style-library` 技能生成。

图片风格大致按话题判断：新手入门、小白体验、工作日运动穿搭、练后好物分享偏真实生活感照片；零基础教学、技能干货偏教程图/教学感图片；赛事信息集结偏真实赛事图、选手图和现场氛围图；圈子乱象吐槽、圈子八卦分享与讨论偏漫画、插画或梗图感配图。所有图片都避免硬广感，尽量自然、适合发动态。

网络图优先使用 Pexels、Unsplash、Wikimedia Commons、官方赛事/场馆/协会图片等来源。图片要避免缩略图、低清图和模糊图，优先长边至少 1600px，最低不低于 1200px。使用网络图时，在当天目录保存 `图片来源.md`，记录来源 URL、作者/平台、许可证或使用说明。

以后只要说“生成今天的 KPI”或“继续做今天的”，就按 `AGENTS.md` 的规则执行。
